## 关于 AI 组

AI 组是一个**以兴趣为驱动**的实验型小组。我们不是教"AI 速成"，而是带着你从最基础的数学 + 编程出发，一步步走到能独立做出可演示的 AI 项目。

## 组内规划

- **概览**：我们致力于提供学习交流平台，包括但不限于机器学习、数据挖掘、深度学习、计算机视觉等方向。在前期为成员个性化定制学习路线，每周开展组会交流学习进度以及学术分享。
- **培养合理**：技术发展兼顾深度和广度。提供一套完整的机器学习与深度学习体系，保证小白友好，同时让有基础的同学能深入到自己感兴趣的方向。
- **氛围轻松**：俱乐部是温馨的组织。AI 组采取导师制——希望和大一学弟学妹成为朋友，更希望大家能真正在 AI 组学到东西，交到朋友。
- **活动有趣**：不定期组织技术沙龙，不仅能学到前沿实用的技术，也能结交到各个领域的学术大牛。

## 你将获得

1. 论文复现能力——从 arXiv 一篇新论文到完整跑通的代码
2. 大模型 / 视觉 / 强化学习等方向的实战项目
3. 与计科院老师合作的机会、显卡算力支持
4. 学术 / 工业界双轨的视野，组员可保研、可实习、可创业

## 学习路径

```
Python + NumPy + Pandas  →  机器学习基础 (吴恩达 CS229)
  →  深度学习核心 (CS231n / 李沐)  →  PyTorch 实战
  →  选定方向（CV / NLP / 多模态 / Agent）
  →  复现论文 / 参加比赛 / 做项目
```
