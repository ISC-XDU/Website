## 关于 Web 开发

Web 开发是指针对用户需求，利用前后端技术，打造静态或者可用于数据交互的网站。

## 你将收获

- 如何制作一个**基本**的网页（比如你现在看到的这个页面）
- 如何**提升开发效率**，分分钟写出简洁漂亮的界面
- 快人一步学习**语言**、**数据库**知识
- 体验**和同伴一起开发**的乐趣，收获友谊
- **学习能力**大大提升

## 特色

- **上手迅速**：做一个最简单的静态页面只需要 html、css、JavaScript 一些基础知识，随意打开一个编辑器甚至是记事本即可进行简单开发。至于数据处理、交互这一块儿，数据库的增删改查操作学起来也是相当快。
- **设计感强**：好的页面就像时兴、美丽的衣裳，你将作为一个设计者，以上帝的视角去审视网页的布局结构、实现细节。同样，一张设计优良的数据表在处理海量运行数据时将大大提升效率。
- **市场需求**：现在网站需求非常庞大，从小作坊、小工厂到大企业、高校，网站即是它们一个衡量体量与价值的标准。
- **技术链完整**：当前一个较大型网站的开发一般是使用前后端分离技术，后端考虑逻辑处理、数据交互，前端只需要设计页面、进行美化，而这两者的技术体系都相当成熟。
