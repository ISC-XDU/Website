## 关于 Web 开发

Web 开发是指针对用户需求，利用前后端技术，打造静态或可用于数据交互的网站。

## 你将收获

- **做出能跑的产品**：从一行 HTML 到一个完整网站，你能在 1-2 个月内做出能上线的真实作品。
- **全栈视野**：前端到后端、从交互到数据库，建立完整的工程认知，不只会写局部代码。
- **团队协作**：真实项目用 Git 分支协作、Code Review、CI/CD，体验工业界开发节奏。
- **审美与表达**：学会用代码讲故事——一个好的页面既是工程，也是作品。
- **学习能力**：在 Web 组你会不断接触新框架、新工具，自学能力会大幅提升。

## 学习路径

```
HTML / CSS 基础  →  JavaScript 核心  →  选一个前端框架
  →  Node.js / Python 后端入门  →  数据库基础
  →  全栈项目实战（俱乐部官网 / 个人作品集 / 内部小工具）
```

## 实战产出方向

- 俱乐部官网 / 招新活动页（像你现在看到的）
- 社团内部工具（报名系统、签到、抽奖）
- 个人作品集 / 博客
- 校园信息聚合小程序 / 微信 H5

## 我们的氛围

- 每周一次技术分享，组员轮流讲、轮流 review
- 真实项目优先，不搞"造火箭"式 demo
- 鼓励产出可见作品，让你的成果能被看见
- 不卷时长，按兴趣和节奏走
