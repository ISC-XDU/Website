## 关于 Agent 组

Agent 组是浪潮技术部 2024 年新设的方向。我们关注的是**让 AI 真正帮你干活**——不是聊天框里问问题，而是把它接到你的工作流里，自动化重复劳动。

## 一些你可能马上想做的项目

- **自动整理周报**：把一周的群聊记录 / 文档喂给 AI，自动生成结构化周报
- **抢课 / 选课小助手**：浏览器自动化 + 监控 + 通知
- **简历筛选工具**：批量解析 PDF 简历 + AI 评分
- **社团信息聚合**：自动抓取 / 汇总 / 分类各个群、公众号的内容
- **个人知识库**：把所有看过的论文 / 文章 / 笔记塞进向量库，问它就能找到

## 学习路径

```
会用 ChatGPT / Claude 网页版
  →  学会调用 API（OpenAI / DeepSeek）
  →  Prompt 工程基础
  →  接 LangChain / LlamaIndex 做 RAG
  →  用 n8n / Dify 编排工作流
  →  做出属于你的自动化小作品
```

## 为什么现在加入

Agent / AI 自动化的浪潮刚刚开始。会调 API + 会写胶水代码 + 懂业务场景——这三个组合在就业市场极度稀缺。我们组就是培养这种"工程 + AI + 业务"复合能力的地方。
